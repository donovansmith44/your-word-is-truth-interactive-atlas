# Bible Explorer Field Guide

A standalone, single-page explorer of this codebase: every crate, module and
file explained at three depths (plain English -> new to Rust -> every detail),
with a 100-entry Rust glossary linked from each file's concept chips.

- `index.html` -- the page (no build step; open it in a browser). It loads `data.js`.
- `data.js` -- the merged content, generated by `build.py` from `data/*.json`.
- `data/*.json` -- one file per area, written from the source at commit 753a753
  (2026-09-15) by reading every file; `WRITER-BRIEF.md` is the schema and the
  house style the writers followed.
- Regenerate after editing any `data/*.json`: `python build.py`.

Published copy: https://claude.ai/artifact/Ea4HeWWZkQo9ZG4YqN6oVZ

The guide describes the code as of 2026-09-15; it is documentation, not a
build input, and nothing in the app reads it.
